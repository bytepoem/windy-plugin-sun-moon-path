# 翻译维护

`src/uiLanguage.ts` 是插件支持语言的唯一注册表。首次选择、设置选项、存储值校验和日期 locale 都从这里读取；插件语言独立于 Windy 语言。

新增语言时：

1. 在注册表中添加语言代码、名称和 locale，明确地点搜索能力、云层表头布局、帮助图及更新日志使用的语言。
2. 在本目录所有 `defineMessages` 字典及 `src/pluginTranslations.ts` 中补齐对应语言。字典按功能组织；完整句子、动态参数与语序归字典负责，组件不判断语言代码或传递语言布尔值。
3. 运行类型检查、lint、测试和构建，验证首次选择、设置切换、重新打开、动态提示、地图标注和移动布局。`uiLanguage.test.ts` 检查注册语言覆盖、嵌套字段及数组长度，并渲染实际组件。

`defineMessages` 从中文推断字段与参数类型，要求其他注册语言完整匹配。不要用缺项占位、静默回退或扩大类型来绕过检查。

历史更新日志仍遵循原有 `zh` / `en` 发布契约；`releaseNotesLanguage` 明确指定显示哪种已有日志，不改写历史快照。帮助图也需明确选择已有图或新增翻译图。首次选择提示在用户确认语言前并列显示中英文，各选项显示原生名称。

当前仅提供简体中文和英文。注册表与字典完整不等于新增语言已通过 UI 验收；长文本、日期语序及从右向左排版需要按目标语言验证。
