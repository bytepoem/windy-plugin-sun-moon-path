# Sun & Moon Path for Windy

**中文** · [English](README_EN.md)

在 Windy 地图上规划日出、日落、月亮和银河拍摄，结合天体方向、云层距离、天气与收藏机位选择拍摄时机。支持中英文、桌面端与移动端。

![插件界面](src/screenshot.jpg)

## 安装与上手

当前发布版本：**0.10.4** · [更新记录](https://github.com/bytepoem/windy-plugin-sun-moon-path/releases/tag/0.10.4)

将以下地址填入 Windy 的外部插件加载入口，打开 **Sun & Moon Path**：

```text
https://windy-plugins.com/17629746/windy-plugin-sun-moon-path/0.10.4/plugin.min.js
```

1. **选机位**：点击地图，或输入 WGS84 / GCJ-02 坐标。中文地点搜索需在设置中填写自己的地图服务 API Key。
2. **选时间**：选择日期，通过当地时间条或日月、银心升落按钮跳转到拍摄时刻。
3. **看条件**：查看事件与天气，使用云层或彩虹规划，也可选择 2–5 个收藏机位进行对比。

语言和显示选项在「设置」中调整；详细图例见「设置 → 使用说明」。以下功能说明对应当前仓库，已发布版本的功能以更新记录为准。

## 主要功能

| 功能 | 用途 |
| --- | --- |
| 日月与银河 | 查看升落时刻、方向线、月相、无月和银河观测时段，用天空盘辅助构图 |
| 云层规划 | 选择太阳、月亮或银心，结合预报或手动云高查看云距与视线交点；支持单层、分层和卫星云图对照 |
| 彩虹规划 | 查看日虹／月虹的方向和高度，支持双虹、完整圆圈，以及主虹条件评估 |
| 天气与观测 | 选择 Windy / Open-Meteo 数据源及预报模型，结合天气、月光和目标位置查看观测时段 |
| 收藏对比 | 复用 Windy 收藏，比较机位的天气、天文事件、海拔与光污染 |
| 雷达与显示 | 叠加 RainViewer 雷达；单位跟随 Windy，移动端支持收起、小窗口与全屏 |

## 彩虹怎么用

在「云层遮挡」旁的下拉菜单选择「彩虹」，选择日虹或月虹并调整时间。地图显示虹弧方向与高度，实线表示地平线上，虚线表示地平线下；所选光源低于地平线时不显示虹弧。

点击「评估当前时刻」，查看主虹方向上的降雨、光照，以及独立的地形和沿途低能见度参考。可调整相机离地高度辅助判断地形影响。

**虹弧只用于几何构图，条件等级不是出现概率。** 评估使用小时预报和有限采样，可信度低，不证明同一瞬间雨滴受到光照；月虹不参与条件评估。山体提示不代表彩虹一定被挡，“未发现遮挡”也不代表视线畅通。双虹或完整圆圈能否看到，仍取决于受光水滴和现场视线。

## 使用边界

- **规划时间与现在不同。** 共用时间条按机位当地时区显示，刷新或重新打开时回到当前时间；标有 `now` 的日月方向线始终表示真实当前时刻。
- **天空盘表示方向，不表示距离。** 银河带和虹弧是几何示意，线宽不代表实际角宽，也不保证可见。
- **云距是几何参考。** 当前点云高不代表远方云区，云距计算不检查沿途天气、地形或云厚，不保证目标可见或出现朝晚霞。详见[云层计算原理与限制](docs/cloud-obstruction.md)。
- **数据来源与时次有区别。** 天气、观测时段和收藏对比共用所选来源；自动云高来自 Windy，卫星和雷达显示各自实况时次。缺测保留未知，不自动换源。
- **预报不等于实况。** Open-Meteo 小时降水为前一小时累计量；过去时段的模式数据不是现场观测。请结合最新天气与现场情况判断。

## 本地开发

当前 CI 使用 Node.js 24、npm 11.12.1。

```sh
npm exec --yes --package=npm@11.12.1 -- npm install
npm test
npm start
```

打开 [Windy Developer mode](https://www.windy.com/developer-mode)，加载 `https://localhost:9999/plugin.js`。

运行 `npm run build` 生成 `dist/`，包含脚本、`plugin.json` 和截图。维护文档：[预报请求与组件职责](docs/refactor-0.11.0.md) · [更新托管与发布](docs/update-hosting.md)。
