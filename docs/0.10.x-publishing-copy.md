# 0.10.x 改动汇总与发布文案

范围：0.10.0–0.10.4。依据当前版本日志与 README 整理。已核实 GitHub 0.10.4 为非草稿、非预发布 Release；未核实 Windy 插件列表的审核或展示状态。以下为待复制发布的文案。

## 合并改动汇总（0.10.0–0.10.4）

- 新增太阳、月亮、银心云层几何规划，提供四类云距、地图参考线、六个升落快捷入口与分钟级时间条。
- 支持预报云底、云量剖面、温湿剖面和手动海拔四种云高方式，可切换卫星实况与预报云图。
- 天气表格、观测时段与收藏机位对比支持 Windy / Open-Meteo 来源切换，显示单位跟随 Windy。
- 完善中英文图解、移动端布局、雷达时次与页面切换；更新日志改用 Netlify，支持失败重试；关于页新增关注与自愿支持入口。

## 小红书文案

### 标题

拍日落月升，云在哪也一起看☁️

### 正文

我做的 Windy 插件 Sun & Moon Path 正式发布 0.10.4 啦！🎉 这次把 0.10.0–0.10.4 的更新一起介绍，重点是新增「云层遮挡」规划，让拍摄前看云多一份参考。

拍日落、月升或银河，除了看云量，也想知道：目标在哪个方向？云有多高？应该关注多远处的云区？☁️

现在不用离开 Windy，就能：

☀️ 选择太阳、月亮或银心进行云层规划

⏱️ 一键跳到六个升落时刻，用分钟时间条微调

📐 查看遮蔽云距、地平线云距、擦地云距和最远无云距

🗺️ 在地图上查看视线交点与距离弧线

📖 对照中英文图解理解各项距离

云高也增加了四种参考方式：

☁️ 直接读取预报云底

📊 根据云量剖面识别云层

🌡️ 根据温度与露点估算候选云层

✍️ 手动输入云层海拔

单层和分层都能切换使用，还能查看卫星实况，再切回预报云图，对照当前云系与计划拍摄时段 🛰️

天气和机位对比也一起完善了：

🌦️ 天气表格支持 Windy / Open-Meteo 数据源切换

⭐ 观测时段与收藏机位对比同步使用所选来源

📏 温度、风速、降水、距离和海拔单位跟随 Windy

📱 优化手机布局、雷达时次和页面切换

📝 改善中英文更新日志加载，增加关注与自愿支持入口

比如准备拍日落，可以先选机位和日期，点击「日落」，确认云高后调整时间，再对照地图云区、天气和备选机位 📷

提醒一下：云距是几何参考，不保证目标可见或出现朝晚霞。当前点云高不代表远处云区，卫星实况也不是未来预报，仍需结合现场条件判断。

## Windy 论坛审核上架文案

### 标题（回复原审核帖时省略）

Sun & Moon Path 0.10.4 — Request for plugin list review

### 正文

Hi Windy team,

I'd like to submit **Sun & Moon Path 0.10.4** for review for inclusion in the plugin list. It is an open-source photography-planning plugin with Chinese and English interfaces for desktop and mobile.

The combined updates from **0.10.0–0.10.4** include:

- **Cloud planning for the Sun, Moon and Galactic Center:** map sightline intersections and cloud-distance references, six rise/set shortcuts and a minute-level timeline.
- **Four cloud-height methods:** forecast cloud base, cloud-cover profiles, temperature/dew-point estimates and manual altitude, available in single-layer and layered views. Satellite observations can be viewed separately from forecast clouds.
- **Windy / Open-Meteo weather selection:** shared by the weather table, observation windows and favorite-location comparisons. Automatic cloud heights and forecast map overlays continue to use Windy.
- **Usability improvements:** Windy unit preferences, bilingual diagrams, mobile layout and radar timestamp fixes, Netlify-hosted release notes with retries, and optional support/profile links in About.

Cloud distances are geometric references, not visibility predictions. The plugin does not sample weather or terrain along the full sightline or account for cloud thickness and atmospheric extinction. Satellite observations are not shown as future forecasts.
