## 小红书

### 标题

拍日落别只看云量，还要看云在哪☀️

### 正文

同样是有云，为什么有时能拍到太阳，有时却被挡得严严实实？

除了云量，云的高度、方向，以及你打算拍摄的时间，也值得一起看。

我做的 Windy 插件 Sun & Moon Path 更新到 0.10.0，这次加上了「云层遮挡」规划👇

☀️ 太阳、月亮、银心都能选
可以切换拍摄目标，也可以用自动模式：太阳在地平线上时看太阳，否则看月亮。

☁️ 把云高变成地图上的距离参考
自动读取当前点的云底或分层云高，也能手动输入远处目标云区的高度。地图会画出视线交点、地平线圈和距离弧线，方便继续检查那个方向的云况。

⏱️ 拖动时间，观察参考线怎么变
支持分钟级时间条，也能一键跳到太阳、月亮、银心的升落时刻，提前比较不同拍摄时间。

📖 看不懂云距？加了中英文图解
遮蔽云距、地平线云距、擦地云距、最远无云距，可以对照示意图理解。

🌦️ 天气数据可以换着看
支持 Windy / Open-Meteo，以及 EC、GFS、ICON 模型。观测时段和收藏机位对比也会跟随所选来源；云高和地图云图仍使用 Windy。

另外，温度、风速、距离和海拔等单位现在跟随 Windy，面板布局和雷达开关也做了优化。

用法可以很简单：选机位 → 选日期和目标 → 确认云高 → 拖动时间 → 去地图上检查对应方向的云区。

提醒一句：这是几何规划工具，不是「火烧云保证器」。当前点的云高不代表远处云区，沿途地形、云层厚度和大气通透度仍要结合实况判断。

## Windy 审核帖（英文，回复原审核主题）

Hi @pavelmedia and the Windy team,

I have published version 0.10.0 of Sun & Moon Path and would like to request another review for inclusion in the plugin list.

The main addition is a Cloud Planning tab for the Sun, Moon and Galactic Center. It supports automatic or manual cloud heights and displays spherical-geometry sightline intersections and cloud-distance references on the map. A minute timeline and six rise/set shortcuts help users explore a planned shooting time. A bilingual illustrated guide explains the distance references.

This version also adds Windy / Open-Meteo weather-source selection for the weather table, observation windows and favorite-location comparisons. Cloud heights and map cloud overlays continue to use Windy data, with the source clearly identified. Units follow Windy preferences, and panel layout and radar controls have been improved.

Cloud planning is explicitly presented as a geometric reference. It does not sample weather along the full sightline or predict guaranteed visibility or colorful twilight.
