# 三项实现优化

## 范围与不变量

分三次提交：计算及 DEM 复用、主组件职责拆分、行为测试与日常 CI。
不改变天文算法、预报来源、评估阈值、存储格式或地图功能。

- 主组件拥有规划时间、地点、偏好及地图生命周期；展示组件只接收状态和用户操作。
- 银河的固定赤道坐标可预计算，地平坐标仍使用每次选择的地点与精确时刻。
- DEM 缓存仅在当前评估组件内复用，以数据集、接口和实际发送的坐标为键，最多 8 个批次。
- 相机高度不改变 DEM；每次仍重新计算视点高程和遮挡。缺测及失败批次不缓存。
- 关闭插件立即取消请求；即使底层忽略取消，晚到结果也不得缓存或更新界面。

## 状态、时序与责任

| 入口 | 处理与结果 | 责任 |
| --- | --- | --- |
| 拖动规划时间 | 使用实际时间更新天体与银河地平位置 | 天空盘几何模块 |
| 重复评估／修改离地高度 | 命中完整 DEM 批次，重新算仰角；天气仍独立加载 | 地形 fetcher / 视线 loader |
| 改变采样位置 | 仅相同请求坐标可复用，不复用旧方向的评估结论 | 地形 fetcher |
| HTTP 失败／缺测 | 保留当前部分证据，下次显式评估可重试 | 地形 fetcher |
| 新评估覆盖旧评估 | 中止旧请求；旧请求不得发布或在取消后填入缓存 | 视线 loader |
| 关闭／销毁 | 中止请求，销毁为终态；重新挂载创建新缓存 | Svelte onDestroy / loader |
| 切换设置、关于、说明 | 主组件状态保留；子组件无独立时间或偏好副本 | 主组件 / 展示组件 |
| push／PR | 运行静态检查、测试、构建及本地更新站点校验 | 验证 CI |

不新增持久化或自动重试，不需要数据迁移；回滚对应提交即可。
验证 CI 不持有发布凭据，不上传插件，也不部署更新站点。

## 性能基线

本机 Node/Vite 加载生产模块，预热 50 次，连续采样 400 个不同规划分钟：
优化前几何计算中位约 0.18 ms、P95 0.27 ms；SVG 中位约 0.26 ms、P95 0.40 ms。
这是计算微基准，不代表移动浏览器帧率；没有证据引入额外节流或调度层。
DOM 图层已复用同一 marker，保留既有同步渲染与清理方式。

相同微基准优化后：几何中位约 0.14 ms、P95 0.25 ms；SVG 中位约 0.22 ms、P95 0.32 ms。
单次本机测量仅作参考，不承诺设备上的固定提速比例。
回归测试验证仅修改相机高度时，完整 DEM 的网络请求从两个批次降为零，且仰角重新计算。
