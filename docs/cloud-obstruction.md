# 云层遮挡 Tab

## 参考材料与范围

- [巧摄 + Windy，让你的悬日手拿把掐](https://xhslink.cn/o/qg4XBbWsAc)，笔记 ID `67dec88800000000090171f2`：在日落方向有云的区域取探空数据，输入云高后拖动时间观察视线交点。数值预报与卫星实况应分开判断，能见度和消光也会影响成片。
- [如何学会科学预测朝晚霞](https://xhslink.cn/o/863YGPolCjP)，笔记 ID `66d418b4000000001f0152ef`：用云高算出地图参考距离，再检查目标云区和入射光路的云况、降水及气溶胶。
- [巧摄官方云层距离指南](https://www.planitphoto.com/pdfs/10.PlanIt-User-Guide-Cloud-Distance.pdf)。旧指南的部分临界角与用户提供的新截图不一致；本实现按明确的球面几何求解，不复制旧角度数值。
- [Windy 插件 fetch API](https://docs.windy-plugins.com/api/modules/fetch.html)。复用当前 `header + meteogram + sounding` 请求，无新增气象服务或密钥。
- [Astronomy Engine](https://github.com/cosinekitty/astronomy)：经用户授权新增固定版本 2.1.19（MIT），仅用于云层 Tab 的太阳/月亮/银心位置。其他页面和升落事件仍使用既有 SunCalc。

此版本提供单点云高估算、手动云高、太阳/月亮/银心视线交点及太阳朝晚霞几何参考。六个升落按钮决定目标天体；调整时间保持最后选择的天体，不随太阳高度自动切换。没有沿光路采样气象数据，不输出“必定遮挡”“必定火烧云”或成功概率。用户可以在 Windy 查看远处云区后手动输入其云高；定位点的估算不代表该远处云区。

## 遮蔽目标与时刻

- 默认日落入口；点击升落按钮选择对应天体和时刻，表格列名显示正在计算的目标。手动调整时间取消事件高亮，但不改变天体。
- 时间条固定展示太阳、月亮、银心六个升落入口，各有 SVG 图标、升落箭头及时间提示。六个按钮靠左，右侧切换云图（含卫星实况）；窄屏压缩按钮宽度。目标下拉框已移除，点击按钮同时切换目标和事件时间。
- 月出/月落复用主页面同日同地点的事件；当日缺少所选事件则清除云层图形并提示，仍可手动输入有效时间。非法时间和夏令时空缺不生成场景。
- 月亮模式与太阳模式保持相同六列表格：云层高度、所选天体遮蔽云距、地平线云距、擦地云距、最远无云距和太阳高度角。后三列继续表示由云高推导的太阳照明参考，不改称月亮高度角；月亮地图与太阳模式保持相同的参考线种类和图例：遮蔽视线、地平线圈、擦地弧线及最远无云距弧线，弧线随所选天体方位旋转；显示全部云距时包含最外侧弧线。这些包络为同云高的几何参考，不构成月光照明预测。月面上缘视高度角小于 0° 时提示不可见，不计算或绘制遮蔽交点，仍保留地平线及距离包络参考。上缘使用站心距离和月球赤道半径估算，避免月出/月落附近中心尚在地平线下时误报整个月亮不可见；不判断地形遮挡。
- 切换目标、日期和时间后，表格与云层图形使用同一场景，地图事件线选择实际目标对应的升落方向。天气仍按该场景时刻选取，所有目标共用原有串行同步和销毁流程；不新增请求、监听器或定时器；用户偏好按下述规则保存。

## 单层与分层模式

- 单层和分层均支持 `预报云底 / 云量剖面 / 温湿剖面 / 手动输入`。单层默认预报云底，分层默认云量剖面；只运行当前选中的自动方法。预报云底按 `meteogram.ts` 选最近时次，剖面按自己的 `ts` 选时次；不插值，不外推，最近时次相差超过 90 分钟则无数据。
- 点位云底按 AGL 米读取，加 `header.modelElevation` 转为几何计算使用的 AMSL 米；界面同时标注离地云底和计算海拔。模型高程缺失时不替换为地点高程。零 AGL 是有效气象值；转换后非正或超过 30000 米则不绘制球面参考。
- 单层和分层分别保留自动/手动选择及手动高度，切换不覆盖另一模式的输入。首次进入手动且未保存高度时，单层填入 2000 米，分层分别填入 2000/4000/6000 米；主动清空后保持空白；分层保留原有三个类别和独立开关。
- 空值、非法数值和超出预报范围均不替换为剖面估算，也不解释为无云；用户可主动切换高度来源。自动数据不会覆盖手动高度。
- 2026-09-07 现场核验 Windy 51.1.2：成都（30.67, 104.06）及拉萨（29.65, 91.13）ECMWF 返回有效云底，GFS/ICON 抽样云底为空；此结果仅为当次抽样，不作为模型能力硬编码。拉萨模型高程 4163 米、地点高程 3656 米，首个 ECMWF 云底 1946 米 AGL，换算 6109 米 AMSL。
- 高度基准证据：Windy 官方云底说明采用离地高度；当前 `_shared-create-weather-rendering-data.js` 将专用字段直接交给云底行，仅在整个字段缺失时计算离地云底；山地返回值也低于地面海拔。插件不复制 Windy 的字段缺失估算分支。
- 单层只是选定参考高度，不能代表所有云层；仍未验证远方云区、沿途地形及消光。

## 剖面识别与来源切换

- 云量剖面使用 `cloud-*` 与 `gh-*`，云量阈值默认 10%，范围 1～100%。温湿剖面只使用 sounding 中同层同一时次的 `temp-*`、`dewPoint-*` 和 `gh-*`；温度与露点均为 K，相减得到摄氏温差，默认阈值 2℃，范围 0～10℃。露点高于温度时按零温差参与筛选。缺少温湿字段不改用云量或其他来源。
- 温湿模式是露点差经验筛选，不作冰面饱和修正，不把 LCL/CCL 当云底，也不从卫星图反推高度。它输出候选云层，不代表实测；降低温差阈值会使条件更严格。单个合格采样点也只作为候选参考，不证明有已解析的云厚。
- 两种剖面共用连续层提取：缺测、地下层、非法或非递增高度打断连续性；首个符合条件的采样高度用于几何计算。如果紧邻下方采样有效且不符合条件，则两者构成云底海拔区间，否则下界未知。单层只取最低检出层；分层保留所有分离层，跨低中高边界的连续层按其底部分类。
- 预报云底也可用于分层：按 AGL < 2000 米为低、2000～6000 米为中、≥ 6000 米为高，只生成一个参考层；其他层显示未知，禁用所属类别后不将该值移入其他类别。
- 模式切换不新增网络请求、定时器或监听器，复用原有地点/模型请求、过期响应检查和 onDestroy 清理；表格、地图和对外规划距离统一消费同一个解析结果。手动高度独立于预报失败。
- 偏好沿用当前存储键，只增加单层/分层自动来源及独立温差阈值；旧偏好缺少新字段时使用既有单层预报云底、分层云量剖面的默认行为。回到旧代码时旧读取器忽略新增字段；不存储自动生成的云高。

## 数据与几何约束

- 读取每个真实气压层的 `cloud-*` 和 `gh-*`，不把低中高云量百分比转换成高度，不把单个 `cloudBase` 当作三层云底。
- 按模型网格高程 `header.modelElevation` 以上的高度将独立云层起始点归入低（< 2 km）、中（2–6 km）、高（>= 6 km）档，不使用地点高程 `header.elevation` 替代；缺少模型高程时不估算自动云高。层高使用海拔米；气压层位势高度在当前垂直分辨率下近似几何高度。
- 可调检出阈值默认 10%，这是云量筛选条件，不是光学不透明度或遮挡概率。每一段连续检出的采样层作为独立层保留，不跨缺失云量合并。
- 第一处达到阈值的采样高度用于计算；如果前一个高度有有效且低于阈值的云量，显示两者之间的云底估算区间。该区间不是测量误差置信区间，离散气压层可能漏掉薄云。
- 单点未检出独立云底、数据不可用、手动停用分别呈现。跨档连续云层只归入其起始档，避免重复计数。
- 按真实 `ts` 选择最近时次（最多相差 90 分钟），显示所采用的预报时刻；禁止跨预报首尾外推或跨大时间缺口取值。不对云层形成和消散做线性插值。
- 用户手动输入使用当前海拔单位，内部转换为米，允许大于 0、最高 30000 米；云距使用零高度观察基准，没有相机离地高度输入。自动刷新不覆盖手动值。浏览器保存遮蔽目标、单层/分层、云图、阈值、同步开关、各层模式/启用状态和手动海拔；日期、规划时间和预报结果不持久化。手动海拔始终按米存储。
- Astronomy Engine 使用零海拔观察者、站心当日赤道坐标和光行差校正，再通过 Horizon 分别计算无折射几何高度角与 normal 标准折射视高度角。遮挡参考距离使用视高度角，朝晚霞临界判断使用几何高度角；二者不能混用。山地升落时刻可能低于 -1 度，方向仍使用引擎 normal 模式的渐变折射近似；太阳遮蔽距离的显示资格另按中心视高度角 >= 0° 判断。这仍是几何规划参考，不是真实折射光路追踪。不再自行逆解或补偿 SunCalc 的高度角。

令 `R = 6371.0088 km`，云海拔 `h`，`b = acos(R/(R+h))`。巧摄式参考以海平面为基准：地平线云距为 `Rb`，擦地点为 `2Rb`，最远无云距为 `3Rb`，太阳临界几何高度角为 `-2b`。6000 米云对应约 276/553/829 km 和 -5.0 度。三项云距统一采用零高度基准，不加机位地平线下沉量，也不从云高扣除机位海拔。机位高度仅用于升落时刻快捷定位，不进入云距函数或地图绘制状态。

白圈是可见地平线参考；低、中、高云分别使用黄、橙、红色弧线表示上述同高度云层的临界包络，方向随所选时刻的太阳方位旋转，不是该时刻的实际光照边界。异高遮挡云、斜向光路和复杂地形不能直接套用三倍距离结论。

视线交点单独求视方向延长线与云高球壳的最近正交点，输出地表弧长而非斜距。它是规划参考，不是真实折射光线追迹；底层函数允许负视高度角的几何求交，但太阳模式会在中心视高度角 < 0° 时隐藏距离与交点。不计算沿途地形、云光学厚度或天体视圆面遮挡。

2026-09-06 截图回归：2000/4000/6000 米参考值分别为 160/226/276 km、479/677/829 km、-2.9/-4.1/-5.0 度。截图三档遮挡距离反推同一视高度角约 -0.141304 度，代入得到 176.10/241.96/292.55 km。这是几何回归，不把反推角度作为天文算法的校正常数；精确坐标、气压温度及巧摄未公开的折射设置仍可造成实际日期计算的差异。

潘家洞山地截图补充回归：同样三档云高，巧摄 106.62/169.03/218.03 km 反推同一零高度基准视高度角约 0.59504 度。旧插件 54.26/133.56/189.35 km 则对应约 1201 米机位海拔和 0.59946 度视高度角；几十公里误差来自错误扣除机位海拔。云距 API 已移除机位海拔参数，界面与地图共用同一基准，不能只修正显示值。采用插件反推角度 0.59946 度、零高度基准时约为 106.32/168.68/217.65 km；剩余小差异须区分天文输入与几何算法，不能硬编码截图角度。

最终端到端回归使用用户截图确认的坐标 24.918759, 112.658726、2026-09-06 18:39 Asia/Shanghai。Astronomy Engine 给出视高度角约 0.5949585 度，直接计算显示 106.62/169.04/218.04 km，与巧摄截图原始距离的差值均小于 0.01 km。相邻分钟另行测试，避免把 18:38 的结果当作 18:39；界面通过顶部日期和当地时间输入框选择该时刻，结果标记为“自选”。

## 状态与责任

| 触发 | 数据与输入 | 地图与异步动作 |
|---|---|---|
| 打开云层 Tab | 复用主组件当前点预报；保留本实例手动云高 | 建立独立云图层和宿主监听；保留实时天体方向线，事件方位线跟随云层 Tab 的升落选择 |
| 更换摄影点/模型 | 主组件请求标识变化，旧 payload 不再传入 | 旧自动云层立即撤销；请求取消与迟到结果检查沿用天气流程 |
| 切换目标、升落或日期、定位 | 默认复用当前日期和定位的升落事件时刻；可输入当地时间进入自选模式，再点击升落按钮恢复事件时刻。自选时间随顶部日期及定位时区解释，不覆盖手动云高 | 串行同步模型、图层、时间；新版本作废旧队列后续动作；无所选事件或输入时间无效时清除参考线并提示 |
| 缺测/网络错误 | 自动层不可用，手动层仍可计算；可重试原请求 | 几何参考只依赖有效坐标、时间、云高；底图同步异常不清除参考线，而是显示同步状态 |
| 独立几何模式 | 手动输入可用于预报范围以外的日期 | 停止驱动宿主天气，明确标注底图未同步 |
| 从宿主修改时间/模型 | 规划日期和时间由插件持有，不接受宿主覆盖；模型仍跟随 EC/GFS/ICON | 宿主不匹配时保留规划参考线并显示“底图未同步”；重新同步恢复插件的规划时刻 |
| 停用/启用云层 | 保留手动高度，仅切换绘制资格 | 使用专属 cloud-layer--inactive 类，避免 Windy 全局 disabled 禁止整行点击 |
| 移动端收起 | 记住原 Tab，切换到统一事件摘要；云层组件销毁并释放监听/图层 | 展开恢复原 Tab 和保存的云层偏好；临时规划时刻按现有事件入口重新建立 |
| 离开 Tab | 保留本实例手动云高设置；自选时间随子组件销毁重置 | 删除云图层和三个 store 监听；天文图层恢复顶部事件筛选 |
| 关闭插件 | 主组件中止天气请求、使请求 ID 失效 | 子组件销毁及队列版本失效，无新增定时器或残留图层 |

本功能不涉及数据库、后台任务或部署迁移；发布/回滚仍使用插件现有版本机制，没有修改版本号或正式截图。


## 银心与 2026-09-08 巧摄截图核对

- “遮蔽银心”沿用项目银河摄影参考点：固定赤经 266.405°、赤纬 -28.9361111111111°，由 Astronomy Engine Horizon 按当地日期恒星时转为高度角和方位角，并使用 normal 折射。此处直接使用固定赤道参考坐标，不将其作为 J2000 坐标做岁差转换；这是摄影银带参考，不是物理银心 Sgr A* 的精密星历。既有银河窗口继续使用原来的恒星时算法，仅共享参考点常量。
- 银心升落通过当前摄影参考点的视高度角过零计算，按当地日界逐分钟扫描并细化到毫秒；使用交点可见侧，点击银心升落时仍可计算地平线云距。无升落事件时按钮禁用。日期、地点、时区变化后重算事件，拖动时间条不重扫全天。
- 银心低于视地平线时，表格不提供遮蔽云距，地图不绘制银心视线及交点；高度决定的参考圆仍保留。选择银心时不显示太阳/月亮升落事件线，避免冒充银心方向。沿用现有云层 controller 和 onDestroy，不增加监听器、请求或定时器；偏好使用独立版本化存储键，旧版本回滚会忽略该键。
- 截图：2026-09-08 20:07 UTC+8，清远“广州机位”，银心高度角 +34.1°、方位角 196.5°；中间相机俯仰 -74.3° 不是银心高度角。
- 仅把截图显示的 34.1° 代入既有球面交点：2000/4000/6000 m 得 2.952051/5.900234/8.844560 km（显示 2.95/5.90/8.84 km）；截图为 2.95/5.89/8.84 km。中云相差约 10 m，不能宣称三档逐字一致，也不为此硬编码修正。显示角度只保留一位小数，不能用该舍入值代替完整天文计算。
- 同三档高度的地平线云距 160/226/276 km、最远无云距 479/677/829 km、太阳临界高度角 -2.9/-4.1/-5.0° 均与截图一致。这些仍是云高对应的太阳几何参考，不是银心照亮云层的边界。

- 口径对照：采用 [Sgr A* 测量坐标](https://arxiv.org/abs/2212.00632)并经 [Astronomy Engine 当日坐标转换](https://github.com/cosinekitty/astronomy/blob/master/source/js/README.md)会得到约 34.1600°、196.0147°、2.95/5.89/8.82 km。本功能选择与既有摄影参考点及巧摄截图一致的口径；截图吻合并不证明巧摄内部的具体实现。


## 紧凑时间条

- 面板段落取消浏览器默认上下 margin，控件、提示、表格、图例采用 6 px 行距；表格数据行上下内边距 4 px。
- 全天时间条 00:00–23:59，步长 1 分钟；支持鼠标、触摸、键盘方向键以及直接填写 HH:mm；已移除前后一分钟按钮。按本地墙上时间显示，夏令时不存在的分钟明确不可用；重复分钟沿用首个时刻规则，事件按钮则保留其精确时间戳。
- 六个事件按钮仅显示与顶部一致的太阳/月亮 SVG、同风格银心旋涡 SVG 和升落箭头，不显示时间，完整事件名称保留在 title 与 aria-label。去掉六个圆点及“当地时间”可见标签；六个按钮靠左并排一行，右侧切换云图（含卫星实况）；可填写的时间框、尽可能伸展的滑条与预报时次位于下一行，桌面行高 28 px、触屏约 34 px。模型和单层/分层放在表格上方。
- 拖动时仅更新表格和地图几何预览，并使旧同步队列后续写入失效；change、blur 或 pointercancel 后提交最终时刻，再串行同步 Windy。点击升落入口保留事件秒级精度，分钟刻度只负责展示与手动选择。
- 日期、地点变更时重新查找所选事件类型，无该事件则清除场景，不沿用前一天的时间戳。未增加手工监听器或定时器；Svelte 释放原生输入事件，云图层、tooltip 和 store 监听仍由现有 onDestroy 释放。

- 云层子组件向主地图传递当前规划时间戳。完整重绘与原有每 5 秒实时线刷新共同使用该时刻，拖动期间不等待 Windy 同步；离开云层 Tab 后恢复真实当前时间。无有效规划时刻则清除实时线，不偷偷回退到现在。新增逻辑不注册监听器或定时器。

- 云层 Tab 不再提供独立透明度或保存独立 opacity 字段；所有日月方位线、银心视线和云层参考线均读取“设置 → 线条透明度”的已有偏好。同步云图控件行窄屏允许换行，不再产生横向滚动条。

- 云层 Tab 的实时方位线按遮蔽计算实际目标筛选；点击升落按钮同时更新目标和时刻，手动调整时间保持已选目标。两条线共用 Astronomy Engine 的方位角与固定 2 km 步长的球面采样路径，重叠路段顶点一致；不再将 SunCalc 实时方向与 Astronomy Engine 遮蔽方向混用。完整重绘和每 5 秒刷新均遵循此规则，离开 Tab 恢复原有日月实时方位线。

- 太阳遮蔽云距仅在太阳中心视高度角 >= 0° 时显示；低于地平线时距离显示 `--`，撤销对应视线与交点，其他云高几何参考列和圈弧保留。此显示资格由 cloudTargetPosition 统一控制，底层球面求交函数仍可独立用于几何验证。月亮的上缘可见判定及银心规则保持不变。

- 单层或分层选择云量剖面时显示“仅考虑云量 ≥”，默认 10%；温湿剖面显示独立温差阈值，预报云底和手动输入不显示剖面阈值，但保留各自已选值。云量阈值不再附带独立说明按钮；所有来源说明默认收起，点击高度来源右侧的 ⓘ 一次展示四种来源的说明。


## 卫星云图与控件布局

- 模型和单层/分层分别显示“模型”“云层”标签，保留 aria-label，与高度来源尽量同排；来源说明默认折叠，通过高度来源右侧 ⓘ 展开于表格上方；切换来源后重新收起。有有效云高但目标不可见时，红色提示位于结果表下方。云距单元格只显示数值或 --，不再显示日落、自选等事件文字。
- 云图菜单可选择 Windy `satellite` 图层。卫星采用 Windy 自己的实况时间轴，只核对 overlay 是否一致，不向其写入所选预报模型或计算时间；计算仍使用原来的地点、预报模型和时刻。没有升落事件时也可切换卫星或预报图层；无计算时刻时只同步图层与模型，不写入时间。
- 切回预报云图前，通过宿主 close({ disableClosingAnimation: true }) 立即释放 radar-plus 时间订阅，避免 500 毫秒退出动画期间覆盖计算时间；随后按既有队列恢复图层、模型、计算时刻同步；连续切换与关闭插件仍通过 revision 使旧任务失效。卫星模式不把宿主产品 satellite 当作预报模型，不新增监听器或定时器。

- 六种升落事件选择由父组件保留，切换 Tab 后银心目标不会被此前日月选择覆盖。当天无对应升落事件的按钮仍保持禁用。
