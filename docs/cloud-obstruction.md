# 云层计算原理与限制

云层 Tab 用于太阳、月亮和银河摄影的云距规划。它把当前点的预报云高或手动输入的云海拔转换为地图参考距离，不沿光路采样远处天气、地形、云厚或消光，不保证目标可见或出现朝晚霞。操作入口见 [README](../README.md)。

## 云高来源与高度基准

单层默认预报云底，分层默认云量剖面；两种视图均支持以下四种方式，缺测不自动切换方法。

| 来源 | 数据与规则 | 限制 |
| --- | --- | --- |
| 预报云底 | Windy `meteogram.cloudBase` 为离地高度（AGL），加 `header.modelElevation` 得到计算海拔（AMSL） | 只代表一个参考层，不能推导三层云底 |
| 云量剖面 | 同一时次的 `cloud-*` 与 `gh-*`；云量默认 ≥ 10%，可调 1～100% | 阈值是检出条件，不是光学厚度或遮挡概率 |
| 温湿剖面 | sounding 同层同一时次的 `temp-*`、`dewPoint-*`、`gh-*`；温度－露点默认 ≤ 2℃，可调 0～10℃ | 经验候选层，不作冰面饱和修正，不等同实测云底 |
| 手动海拔 | 按界面海拔单位输入，内部按米保存；有效范围为大于 0、至多 30000 米 | 应输入云层海拔，而非相对相机的高度 |

- 模型高程缺失时不以地点高程代替，自动云高不能据此生成几何参考。零 AGL 是有效气象值，但转换后的海拔仍须满足绘制范围。
- 预报云底使用 meteogram 自身时间轴；剖面使用其自身时间轴。选取最近真实时次，最多相差 90 分钟；不插值、不超出预报首尾取值。
- 云量剖面优先使用 sounding，整体缺少 sounding 时使用 meteogram；温湿剖面只使用 sounding。温度与露点均为 K，相减得到摄氏温差；露点高于温度时按零温差筛选。
- 剖面中的缺测、地下层、非法或非递增高度会打断连续层。每段首个合格高度用于计算；紧邻下方样本有效且不合格时，两者构成云底区间，否则下界未知。区间不是置信区间，离散气压层可能漏掉薄云，单个样本也不能证明云厚。
- 单层只取最低检出层；分层保留分离层。按云底高于模型地形的高度分为低（< 2 km）、中（2～6 km）、高（≥ 6 km）；跨档连续层只归入底部所在档。分层预报云底仅填入一档，其他档未知，禁用后不移入其他档。
- 手动输入不受自动刷新或请求失败覆盖。单层和分层保留各自输入；首次进入手动且无保存值时，默认分别为 2000 米及 2000/4000/6000 米。

当前点云高不代表远处目标云区。天气选择 Open-Meteo 时，自动云高仍单独取自 Windy；选择 Windy 时复用天气原始预报。

## 几何口径

所有云距以海平面上的观察者为基准，云海拔不扣除机位海拔，也不增加机位地平线下沉量。机位海拔可以影响升落快捷时刻，但不进入云距函数。曾经将机位海拔带入云距计算，会在山地造成几十公里偏差，因此表格和地图必须共用这个基准。

令地球半径 `R = 6371.0088 km`，云海拔 `h` 以 km 计，`b = acos(R / (R + h))`（弧度）：

| 参考量 | 计算 |
| --- | --- |
| 地平线云距 | `R × b` |
| 擦地云距 | `2 × R × b` |
| 最远无云距 | `3 × R × b` |
| 太阳临界几何高度角 | `−2 × b`，显示时换算为度 |

6000 米云对应约 276 / 553 / 829 km 和 −5.0°。这些是同高度云层的太阳照明几何包络，不是当前时刻的实际光照边界；异高遮挡、斜向光路和复杂地形不能直接套用三倍距离结论。

遮蔽云距单独计算视方向延长线与云高球壳的最近正向交点，输出地表弧长而非斜距。它不是物理折射光线追迹，也不计算天体视圆面遮挡。

白圈表示地平线云距，低、中、高云使用黄、橙、红色参考线。弧线随当前所选天体的方位旋转；月亮和银心模式中的擦地、最远无云距及太阳高度角仍表示太阳几何参考，不代表月光或银心照明。

## 天体与时间

云层位置使用 Astronomy Engine；既有日月升落事件与其他页面继续使用 SunCalc。太阳/月亮采用零海拔观察者、站心当日赤道坐标及光行差校正，Horizon 的 normal 折射结果用于遮蔽视线，无折射几何高度角用于太阳临界角判断，两者不得混用。

| 目标 | 遮蔽距离和交点的显示条件 |
| --- | --- |
| 太阳 | 中心视高度角 ≥ 0° |
| 月亮 | 月面上缘视高度角 ≥ 0°；上缘由站心距离和月球赤道半径估算 |
| 银心 | 摄影参考点视高度角 ≥ 0° |

目标不可见时隐藏遮蔽距离与交点，保留仅由云高决定的距离参考。底层球面求交仍允许负视高度角用于几何验证。

银心使用与既有银河规划共享的摄影参考点：赤经 266.405°、赤纬 −28.9361111111111°，直接按当日恒星时转换，不作 J2000 岁差转换。这是摄影银带参考，不是 Sgr A* 精密星历；与巧摄截图吻合也不能证明其内部算法。

- 六个升落按钮选择天体和事件时刻，调整时间保持所选天体。日月事件复用主页面；银心事件按当地日界扫描视高度角过零点并细化。
- 当地时间输入按定位点时区解释；夏令时空缺无效，重复分钟选择首次出现。升落按钮保留事件秒级精度，手动时间步长为一分钟。
- 日期或地点变化后重算所选事件；事件缺失或时间无效时清除场景，不沿用旧日期，也不回退到当前时间。

## 状态、同步与清理

表格、云层地图和规划方位线使用同一目标与时刻。拖动时间只更新几何预览并使旧同步队列失效，提交时间后再同步 Windy。

| 触发 | 行为 |
| --- | --- |
| 更换地点、模型或天气来源 | 由预报 controller 失效旧请求和结果；迟到响应不得覆盖当前场景 |
| 预报失败或缺测 | 自动云层不可用，可显式重试；有效手动海拔仍可计算 |
| 关闭底图同步 | 可独立规划预报范围外的日期，明确标注底图未同步 |
| 从宿主修改时间 | 不覆盖插件规划时间；不匹配时显示未同步状态 |
| 切到卫星 | 只同步图层，不写入预报模型或规划时间，使用 Windy 实况时间轴 |
| 切回预报云图 | 立即关闭 radar-plus，释放其时间订阅，再顺序同步图层、模型和时间；无有效时刻时不写时间 |
| 移动端收起或离开云层 Tab | 云层子组件销毁，移除图层和监听；展开恢复原 Tab 与保留设置，重新建立事件时刻 |
| 关闭插件 | 中止预报请求，使迟到结果和同步队列失效，释放监听及插件图层 |

云层组件的三个 store 监听由 onDestroy 成对移除；异步地图同步在每个步骤检查实例状态和 revision。地图同步失败显示状态，不因此删除仍有效的几何参考。

偏好由 `cloudPreferences.ts` 保存单层/分层、目标、来源、云图、阈值、同步开关及手动海拔；不保存日期、规划时间或自动预报结果。线条透明度共用插件设置。
